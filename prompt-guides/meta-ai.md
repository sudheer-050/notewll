Write the prompt the way Meta recommends prompting Llama-based assistants:

- Give a clear, explicit instruction and the role the assistant should take when it matters.
- State the output format and length explicitly; these models follow explicit limits well.
- Put any supplied text after the instruction, clearly separated.
- Ask for step-by-step reasoning for multi-step problems.
- Keep instructions short and unambiguous.
