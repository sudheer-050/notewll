Write a clear prompt that works with any AI assistant:

- State the task first, with a specific action verb.
- Add the context the person gave: purpose, audience, background.
- State constraints: length, tone, format, what must be included.
- Separate any supplied text from the instructions.
- Say what to do rather than what not to do.
