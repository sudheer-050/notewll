# Local streaming dictation

Shortcut dictation recognizes speech while recording and finalizes recognized text on release. Raw text keeps the recognition result unchanged. Modified text uses deterministic filler/repetition cleanup and selected writing preferences. No separate sentence-editing service is started or awaited.

Saved dictations retain the raw recognized text alongside the final output. Silence, empty recognition and quick shortcut taps return quietly. Optional accurate speech recognition remains independent from enhanced notes.

Historical replay timings are not current microphone-to-editor latency measurements. Physical microphone, typing into target applications, and real-room recognition accuracy require desktop acceptance. See PUBLICATION_0.10.0.md for the current automated verification scope.
